# Research Paper Review

A collaborative repository for collecting, screening, and reviewing academic research papers.

## Contributors and collections

- [Iftehaz Md. Iftekhar](Iftehaz%20Md.%20Iftekhar/) — papers and review index
- [Meherun Nesa](Meherun%20Nesa/) — papers and review index
- [Kahakashan Ashraf](Kahakashan%20Ashraf/) — papers and review index

Each contributor has a **separate top-level folder**. Add research-paper PDFs directly inside that person's folder, and keep their [paper index](https://github.com/iftehaziftekhar22-svg/Research-Paper-Review) up to date.

## How to add a paper

1. Open your named folder.
2. Add a legally shareable paper PDF with the format `FirstAuthor_Year_ShortTitle.pdf`.
3. Edit the same folder's `PAPER_INDEX.md` and add the paper title, DOI / official URL, year, dataset, methods, main finding, and research gap.
4. Update its status: **Found → Screened → Reviewed**, or mark it **Excluded** with a reason in the research-gap column.
5. Check against all folders and the existing shared tracker to avoid duplicate papers.

## Quality and collaboration rules

- Prefer published peer-reviewed literature and verify bibliographic details from the original source.
- Do not invent references, DOI numbers, accuracies, dataset sizes, or findings.
- Add a link rather than uploading a copyrighted PDF without permission.
- Keep filenames descriptive and make commits with clear messages.
- Be respectful of each contributor's folder; coordinate before editing someone else's review entries.
