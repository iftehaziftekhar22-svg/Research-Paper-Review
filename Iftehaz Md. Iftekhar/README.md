# Iftehaz Md. Iftekhar — Research Paper Collection

This folder contains research papers discovered and reviewed by **Iftehaz Md. Iftekhar** for the collaborative literature review project.

## What belongs here?

- Research-paper PDFs that you are permitted to share, named consistently.
- A corresponding entry for **every paper** in [PAPER_INDEX.md](PAPER_INDEX.md).
- For papers that cannot be redistributed, record the DOI or official publication link in `PAPER_INDEX.md` instead of uploading the PDF.

## File naming

Use `FirstAuthor_Year_ShortTitle.pdf` (example: `Rahman_2024_FederatedLearning.pdf`). Avoid generic filenames such as `paper1.pdf` or `download.pdf`.

## Workflow

1. Search trusted scholarly databases, publisher sites, and reference lists.
2. Check relevance, DOI, publication year, and duplicates against the team's existing records.
3. Save a legally shareable PDF here, or record its URL if a PDF cannot be shared.
4. Add a new row to [PAPER_INDEX.md](PAPER_INDEX.md), including methods, findings, and research gap when reviewed.
5. Update the review status as the paper moves from discovery to review.

**Status values:** `Found`, `Screened`, `Reviewed`, `Excluded`.
